Installation & System Replacement

The right system starts with the right assessment.

System replacement should never rely on rule-of-thumb guesswork. In Houston's humid climate, an oversized unit causes short-cycling and clammy air, while an undersized unit runs constantly without cooling effectively. We evaluate square footage, window solar gain, and insulation levels to match proper capacity using Manual J calculations.

25-Point Inspection Protocol

Our P.S.A. includes two dedicated checkups per year to maintain peak performance, extend compressor life, and protect your indoor environment:

Summer Cooling Tune-Up
  • ✓ Test operating refrigerant pressures
  • ✓ Inspect condenser coils & clean debris
  • ✓ Test capacitors & contactor points
  • ✓ Check evaporator coil condition
  • ✓ Measure blower motor amp draw
  • ✓ Flush & treat condensate drain line
  • ✓ Calibrate thermostat differential
  • ✓ Check return air temperature drop
  • ✓ Tighten all high-voltage electrical lugs
  • ✓ Inspect safety float switch
Winter Heating Tune-Up
  • ✓ Electronic carbon monoxide test
  • ✓ Test for combustible gas leaks
  • ✓ Inspect heat exchanger for cracks
  • ✓ Clean & adjust burner assembly
  • ✓ Test ignition system & flame sensor
  • ✓ Inspect flue pipe & chimney draft
  • ✓ Check limit switches & safeties
  • ✓ Test blower assembly operation
  • ✓ Check electrical disconnect switch
  • ✓ Complete visual safety sign-off
